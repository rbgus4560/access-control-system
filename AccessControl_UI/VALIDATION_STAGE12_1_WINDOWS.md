# 11.1 · 메뉴별 별도 창과 간결한 메인 화면

## 적용

서버·인증·등록 앱을 종료하고 정상 버전 폴더를 보관한 뒤 ZIP의 AccessControl_UI 내용을 기존 폴더에 덮어쓴다. Start_Net10.cmd 실행 후 두 앱의 11.1 제목을 확인한다. SQL 재실행·모델 설치·얼굴 재등록은 필요 없다. 새 직원 관리 창 열기 요청을 지원하도록 서버도 함께 업데이트한다.

## 메인과 메뉴

- 메인: 큰 카메라 한 개, 출입 결과, 선택 장비, 얼굴 기준 요약, 실제 카메라/서버 연결 상태, 최근 인증, 현재 시각·실제 영상 수신 FPS, 하단 24시간 타임라인.
- 사용자 목록: 별도 창에서 실제 DB 직원을 조회·검색한다. 행을 선택하면 하단의 인증 기준 선택에 반영되며, 선택 직원 얼굴 불러오기를 눌러 실제 적용한다. 비활성·얼굴 미등록 직원은 기준 불러오기를 안내와 함께 제한한다.
- 사용자 목록의 서버에서 직원·권한 관리: 기존 서버 직원 관리 창을 연다. 해당 창에서 DB 비밀번호를 입력하고 조회·수정한다. 클라이언트에 DB 비밀번호나 직접 쓰기 권한을 추가하지 않는다. 수정 후 사용자 목록을 새로고침한다.
- 사용자 등록: 기존 FaceEnrollment 별도 프로세스. 현재 인증 앱에서 이미 시작한 등록 프로세스가 살아 있으면 중복 시작을 막고 작업 표시줄에서 선택하도록 안내한다.
- 설정: 별도 창의 서버 연결, 카메라·AI, 녹화·보관 탭. 기존 연결 버튼·주소·기준 보정·비교·실행 경로·분석 상세를 이동했다. 설정 창을 닫아도 메인의 카메라·AI·통신·녹화는 계속한다.
- 최근 인증 선택: 별도 영상 창. 서버에서 선택 기록 영상 요청을 보낸 경우도 이 창으로 연결한다. 완료된 로컬 녹화를 재생하고 해당 구간 클립 추출 창을 열 수 있다. 영상 창을 닫아도 메인 LIVE 카메라와 인증은 계속한다.
- 최근 인증은 이번 실행 중 수신한 DB 기록 완료 ACK의 이벤트 ID를 기준으로 최대 10개 표시한다. 과거 DB 전체 이력을 불러오는 목록은 아니다. 전체 이력은 기존 서버 출입 기록을 사용한다. 임의 샘플 행은 표시하지 않는다.
- 타임라인은 메인 하단에 유지한다. 날짜·시각·구간 선택 도구는 접힌 녹화 탐색 도구를 펼쳐 사용한다. 타임라인으로 직접 시각을 고르면 기존처럼 메인에서 녹화 재생하며 LIVE 버튼으로 복귀한다. 최근 기록의 별도 창 재생과 구분된다.

## 첫 연결 순서

1. 서버에서 DB 연결·기존 관리자 선택·TCP 시작.
2. 인증 메인의 설정 열기. 서버 연결 탭에서 서버 연결.
3. 사용자 목록 열기. DB 직원 조회 후 선택 직원 얼굴 불러오기. 기존 9개 샘플 사용 가능.
4. 설정의 카메라·AI 탭에서 카메라 연결. AI 준비·기준 적용 후 정면 보정·비교 시작.
5. 설정 창 닫기. 메인 카메라·기준 요약·출입 결과·서버 영상·녹화가 계속되는지 확인.

## 창 수명 처리

설정과 사용자 목록의 기존 컨트롤을 새로 만들지 않고 별도 창으로 이동한다. 창 닫기 시 호스트에서 컨트롤을 분리하고, 다시 열면 동일한 설정값·연결 상태·참조를 붙인다. 메뉴 중복 클릭은 기존 창을 활성화한다. 본체 종료 시 설정·목록·이벤트 영상 창을 닫고 기존 카메라·통신·녹화·클립 종료 절차를 따른다.

이벤트 영상은 자체 PlaybackPanel과 MediaElement를 소유한다. 처음 열릴 때 자동 목록 조회와 이벤트 조회가 경합하지 않도록 팝업에서는 자동 로드를 생략한다. 별도 영상 창에는 메인으로 돌아가기 버튼을 두며, 메인 카메라가 없는 팝업에 LIVE 화면이 있다고 표시하지 않는다. 재생·클립의 기존 원본 보호 핀을 그대로 사용한다.

## 검증 범위

- 세 WPF 앱의 .NET 10 빌드 성공.
- 기존 FaceChecks·HandoffChecks·NetworkChecks·RetentionChecks 통과. 기존 특징/DB 요청·TCP·영상·녹화·클립·보관 계약의 검사다. 새 WPF 창을 실제 실행한 검사가 아니다.
- 세 메인 화면의 기존 이름 있는 컨트롤 유지 및 전체 소스 XAML 파싱 확인. AI·SQL·Network 소스는 11.0과 동일하다. 얼굴 검출/자동 샘플 선택/판정 임계값을 변경하지 않았다.
- 서버의 사용자 전용 파이프에 open-employees 요청만 추가했다. DB 조회 연결이 준비된 경우에만 기존 직원 관리 창을 연다. 직원 데이터 수정은 기존 창의 DB 작업 경로를 따른다.
- Linux 환경이므로 Windows WPF의 표시·컨트롤 재부착·창 닫기/다시 열기·영상 재생은 실제 PC에서 확인해야 한다.

## Windows 확인

1. 메인에서 설정·DB 입력·분석 정보가 상시 펼쳐져 있지 않고 영상 중심으로 표시되는지 확인.
2. 사용자 목록·설정을 각각 3회 열고 닫아도 정상인지 확인. 중복 클릭 시 같은 창으로 이동하는지 확인.
3. 설정 창에서 연결 후 창을 닫아도 카메라·AI·서버 영상·녹화가 계속되는지 확인. 다시 열어 종료·재연결과 값 유지도 확인.
4. 사용자 목록이 실제 DB 직원인지 확인. 행 선택·얼굴 불러오기·새로고침, 서버 직원 관리 창 열기 확인.
5. 새 출입 이벤트가 DB 저장 완료된 뒤 최근 인증에 한 번 표시되는지 확인. 선택 시 별도 영상 창·클립 창, 창 닫기 후 메인 LIVE 유지 확인. 녹화 중인 구간은 완료 후 재생 가능.
6. 서버의 선택 기록 영상도 별도 창에서 열리는지 확인. 메인 타임라인의 날짜 선택·재생·LIVE 복귀도 별도로 확인.
7. 앱 전체 종료가 정상인지 확인. 아래 숙이기 검출·새 기준의 타인/재시작 검증 등 기존 잔여 항목은 유지한다.
