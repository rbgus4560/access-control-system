# 등록 방향 안내 애니메이션 · 시험 적용 · 2026-10-22

사용자 요청에 따라 카메라는 좌우 반전하지 않고 원본을 유지한다. 등록 화면에 화면 기준 좌우 문구와 단계별 움직이는 화살표를 추가했다. 정면 단계는 원형 표시가 서서히 밝아지고, 좌우·상하 단계는 해당 화살표가 왕복한다. 얼굴을 덮지 않도록 영상 위쪽 안내 영역에 배치한다. 화살표는 실제 얼굴 움직임 추적이나 생체 위조 방지 기능이 아닌 목표 단계 안내다.

## 사용과 원복

등록 창을 정상 종료한 뒤 다시 빌드·실행한다. `dotnet build FaceEnrollment/FaceEnrollment.csproj`를 AccessControl_UI에서 실행할 수 있다. ‘움직이는 방향 안내’를 끄면 즉시 숨겨지고 기존 텍스트 안내는 유지된다. 이 선택은 현재 창에만 적용되며 다시 열면 켜진다. 불편하면 애니메이션 추가 부분을 제거할 수 있도록 별도 EnrollmentMotionGuide.cs에 격리했다.

방향은 본인 몸의 좌우 대신 화면 속 얼굴 기준으로 읽는다. ‘화면 왼쪽’ 안내라면 영상 속 얼굴이 왼쪽을 향하도록 움직인다. 기존 yaw/pitch 부호 설정과 Python 판정·샘플·영상·녹화·저장은 변경하지 않았다. 기기/기존 반전 보정에 따라 화면과 판정이 일치하는지는 실제 카메라로 확인해야 한다. 애니메이션을 켜는 것으로 방향 판정 오류 자체가 교정되는 것은 아니다.

## 검증

등록 앱과 공유 코드 사용 인증 앱(별도 build-check 출력) 빌드 경고·오류 0. 카메라·DB 없이 최소 창 WPF 미리보기 렌더링과 등록 --ui-smoke(설정 2회 열고 닫기·앱 종료) exit 0. 활성 등록 단계이며 신선한 정상 분석일 때만 애니메이션을 표시하고, 종료·분석 지연·수집 완료·선택 해제 때 중지한다. 방향이 같으면 애니메이션을 다시 만들지 않는다. 실제 사람의 좌우 동작과 전체 단계 전환의 현장 시험 및 사용감은 미확인이다.

개발 미리보기는 `--ui-preview --guide-preview --capture-output <절대 PNG 경로>`다. 샘플 LEFT 화살표만 보여주며 실제 AI 결과를 만드는 옵션이 아니다.
