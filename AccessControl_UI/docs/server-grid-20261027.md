# 관제 서버 9분할 화면

## 상단과 우측 패널 후속 정리

사용자의 후속 요청으로 오른쪽 정보 패널과 접기 버튼을 제거했다. 큰 실시간 관제 제목, 상태 설명·문자 배지와 우측 상단 시계도 제거하고 좌측 ACCESS CONTROL 위치와 관제 메뉴 이름을 서버관제로 변경했다. 영상 안의 시간은 유지한다.

카메라 영역 위에 얇은 상태 줄을 두고 우측에 DB·TCP/IP·영상 아이콘과 원형 표시등을 배치한다. DB는 기존 연결 준비 상태, TCP/IP는 수신기 실행 여부, 영상은 최근 수신 유효성을 기준으로 표시한다. 각 아이콘의 툴팁에 상세 문구를 표시하며 TCP 수신 초록색을 특정 클라이언트 연결 완료와 혼동하지 않는다. 큰 상단 영역과 우측 패널이 차지하던 공간을 9분할 영역으로 확장했고 하단 최근 기록은 유지했다.

서버 재빌드 경고·오류 0. 합성 영상의 기본 화면과 최소 크기의 좌측 메뉴 접힘 화면을 렌더링해 배치를 확인했다. 실제 DB·TCP·영상 상태 전환은 이번 미리보기에서 실행하지 않았다. 아래의 우측 패널 접기 설명은 이전 단계 이력이며 최종 UI에서는 패널이 제거되었다.

2026-10-27 사용자 요청으로 관제 서버 UI를 수정했다.

## 최종 구성

- 좌측 메뉴를 접으면 아이콘만 보이며, 선택·호버 박스와 접기 버튼의 기본 테두리를 제거했다. 선택 아이콘 색과 메뉴 툴팁은 유지한다.
- 카메라 영역은 동일 크기의 3×3 타일이다. 각 타일 하단에 카메라와 클라이언트 연결 아이콘·원형 표시등을 배치했다.
- 각 타일 우측 위 확대 버튼은 비모달 큰 창을 연다. 이미 열린 창은 활성화한다. 별도 캡처나 AI·네트워크 프로세스를 시작하지 않고 같은 수신 영상과 상태를 표시한다. 확대 창을 닫아도 원래 관제 화면은 유지된다.
- 시간, 카메라명, 서버의 DB 기록 완료 허가·거부 결과를 영상 안쪽에 배치한다. Uniform 표시의 검은 여백을 제외하고 좌표를 계산한다. 배경 박스 없이 글씨와 그림자를 사용한다. 영상만 거울 반전하며 글씨는 정상 방향이다.
- 오른쪽 출입 판정·인증 클라이언트 패널은 화살표로 접고 펼칠 수 있다. 접으면 영상 영역이 남은 폭을 사용한다.
- 아래 최근 출입 기록과 기존 메뉴 동작은 유지한다.

## 현재 지원 범위

현재 네트워크/DB·녹화 경로는 CAM-01 기준 처리가 있다. 이번 변경은 영상 표시 영역을 9칸으로 만든 UI 작업이다. 기존 CAM-01 스트림은 첫 칸에만 연결하며 다른 칸에 복제하지 않는다. CAM-02~09는 미연결 슬롯이고 두 표시등은 빨간색이다. 실제 9대 동시 수신은 클라이언트/카메라별 스트림·상태·판정·DB/파일 경로 분리가 추가로 필요하다.

우측 정보는 현재 연결된 CAM-01을 기준으로 한다. 이름은 서버의 CAM-01 · 출입구이며 클라이언트에서 바꾼 화면용 표시 이름을 전송·동기화하는 기능은 이번에 추가하지 않았다.

## 수정 파일

- AccessControlServer/CameraTile.cs: 영상·상태·오버레이·확대 창.
- AccessControlServer/MainWindow.xaml: 9분할 배치·접힘 메뉴 스타일·오른쪽 패널.
- AccessControlServer/MainWindow.xaml.cs: 기존 스트림·판정과 타일 연결, 오른쪽 패널 전환.

## 검증

서버 프로젝트 빌드 경고·오류 0. 장치·DB를 시작하지 않는 실제 WPF 미리보기로 기본 9분할, 최소 창 크기에서 양쪽 패널 접힘, 합성 영상의 시간·카메라명·허가 문구, 별도 확대 창을 렌더링해 확인했다.

실제 카메라·서버 통신·DB 인증, 메뉴 마우스 조작과 연속 영상 중 확대 창 갱신, DPI별 배치와 종료·재열기는 이번에 실기 검증하지 않았다. 합성 화면의 초록 표시등·허가 결과는 미리보기 입력이며 실제 출입 허가 증거가 아니다.

실행은 기존 Start_Server.cmd를 사용한다. 실행 중인 창은 재시작해야 변경이 보인다. 별도 검증 출력은 build-check/server-grid-20261027이며 제출용 소스에서 제외한다.
