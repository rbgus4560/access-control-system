# 클라이언트 카메라 중심 화면 정리

2026-10-26 사용자 요청으로 인증 클라이언트 화면을 변경했다. 관제 서버와 AI 분석·통신·녹화 로직은 변경하지 않았다.

- 창 제목을 `Access Control · 클라이언트`로 변경했다.
- 왼쪽 메뉴·최근 인증 목록, 출입 인증 제목·대형 판정 영역, 하단 직원 기준 안내를 주 화면에서 제거했다.
- 카메라·서버 아이콘과 연결 표시등을 배치했다. 최근 영상/서버 응답이 유효한 경우 초록색, 그 외는 빨간색이다. 아이콘의 툴팁과 접근성 이름에 상세 상태를 표시한다. 서버 상태는 실행 여부만으로 연결됨으로 판단하지 않는다.
- 카메라 우측 상단 기어 메뉴에서 서버 연결·카메라 AI·녹화 보관을 선택하면 해당 탭을 연다.
- 설정 창은 940×820에서 640×560으로 줄였다. 최소 크기는 560×460이며 각 탭은 스크롤할 수 있다.
- 설정은 비모달 소유 창으로 유지한다. 열고 닫는 동안 기존 카메라·녹화 처리를 중단하지 않는다. 중복 창은 만들지 않고 기존 창을 활성화한다.
- 기존 판정 상태·최근 이벤트의 내부 갱신 코드는 보존했으며 해당 보조 컨트롤은 숨김 상태다. 화면에서 대형 판정 표시를 제거한 사용자 요청에 따른 것이다.

## 검증

FaceRecognition 프로젝트를 별도 `build-check/client-ui-20261026` 출력으로 빌드해 경고·오류 0을 확인했다. `--ui-preview`로 카메라·DB·네트워크 시작 없이 메인 화면과 설정 창을 생성하고 렌더링했다. 실제 연결 시 표시등 전환, 기어 메뉴 마우스 조작, 카메라·녹화 지속 여부는 실제 장치 환경에서 재확인이 필요하다.

수정 전 네 파일은 `build-check/client-ui-before-20261026`에 보존했다. 실행은 기존 `Start_Client.cmd`가 수정된 소스를 빌드한 뒤 시작한다. 이미 실행 중인 앱은 다시 시작해야 새 UI가 적용된다.

## 같은 날 추가 조정

- 상태 아이콘과 별도 원형 표시등을 카메라 프레임 내부 우측 상단, 기어 왼쪽으로 이동했다.
- 기어 버튼은 흰색 배경과 테두리를 제거하고 투명 템플릿으로 표시한다.
- LIVE CAMERA 옆에 날짜·시간을 배치하고 바깥쪽 상단 상태 영역을 제거했다.
- 설정 탭 선택 UI를 제거했다. 기어 메뉴에서 선택한 설정 영역 하나만 표시하고 창 제목도 해당 항목으로 변경한다. 기존 창이 열려 있으면 그 창의 표시 항목을 바꿔 중복 소유·중복 연결을 피한다.
- 클라이언트 빌드 경고·오류 0. 메인과 서버 연결 설정의 실제 WPF 미리보기 렌더링을 확인했다. 실제 연결·영상·녹화는 이번 미리보기에서 실행하지 않았다.

## 카메라 내부 메뉴와 분석 화면 토글

- 사용자 화면에서 네이티브 ContextMenu가 앱 오른쪽 경계를 넘는 현상을 확인했다. 메뉴와 상태 툴팁을 카메라 내부 Grid 자식으로 바꾸고 우측 안쪽에 정렬했다. 메뉴 밖 클릭 또는 Escape로 닫는다.
- 서버 연결/연결 종료 버튼 사이에 가로 간격 10과 아래 여백 8을 적용했다.
- 기어 왼쪽 분석 토글을 추가했다. 켜짐은 사각 테두리로 표시하며, 기존 카메라 설정의 분석 상세 Expander는 인증 클라이언트에서 제거했다. 등록 앱은 유지한다.
- AI가 이미 생성하는 주석 포함 분석 JPEG를 동일 카메라 영역에 표시한다. 라이브 프레임 위에 지연된 좌표를 덧그리지 않으며 분석 프레임의 나이를 명시한다. 기존 fresh 검사 통과 때만 표시하고, 결과가 없거나 오래되면 분석 표시를 숨기고 라이브 영상과 대기 문구를 보여 준다.
- 화면 토글은 AI 입력, 식별 정책, 전송, 녹화 프레임을 변경하지 않는다.
- 클라이언트 및 등록 앱 빌드 경고/오류 0. 최소 크기에서 메뉴/툴팁 경계와 분석 켜짐 대기 상태, 설정 버튼 간격을 실제 WPF 미리보기로 확인했다. 실제 얼굴 주석과 켜기/끄기 조작, 영상 수신·녹화 지속은 카메라 연결 후 확인이 필요하다.

## 영상 영역의 시간과 출입 판정 띠

- 실제 Uniform 영상 사각형 크기를 계산해 그 안에만 시간·카메라명·판정 띠를 표시한다. 분석 모드도 현재 표시하는 이미지의 비율을 기준으로 한다. 이미지 반전은 영상에만 적용하고 글씨는 정상 방향으로 표시한다.
- 시간은 영상 왼쪽 위에 `yyyy-MM-dd- HH:mm:ss` 형식, 21pt로 표시한다. 오른쪽 아래에는 카메라 이름을 18pt로 표시하며 카메라 아이콘 설명은 연결 상태만 표시한다.
- 최신 관측·시도 ID·서버 응답·직원 기준 조건이 유효하고 서버가 DB 기록을 완료한 허가/거부에만 녹색/적색 하단 띠를 표시한다. 문구는 26pt이며 직원 이름을 포함한다.
- 이벤트 ID별 중복 표시를 억제한다. 2.2초 유지 후 0.6초 동안 사라진다. 기존 판정 유효성 검사 실패 또는 카메라 종료 시 띠를 숨긴다. 표시는 PC 시각이며 원본 MP4에 번인하지 않는다.
- 단일 얼굴 분석 시 MediaPipe의 사각형은 생략하고 dlib 사각형과 랜드마크 점만 표시한다. 다중 얼굴은 개별 영역 표시를 유지한다. 특징 추출·인증 계산은 변경하지 않았다.
- 검증: 클라이언트/등록 앱 빌드 경고·오류 0. 합성 영상 미리보기로 기본/최소 창 크기의 시간 위치와 허가/거부 띠 범위를 확인했다. 실제 서버 승인·연결 중단·카메라 환경의 표시 지속은 후속 확인이 필요하다. Python 구문 및 단일 얼굴 주석의 사각형 수 검사도 수행했다.

## 텍스트만 표시 및 카메라 표시 이름

- 시간·카메라 이름의 배경과 판정 띠 배경을 투명하게 변경했다. 그림자로 가독성을 보완하고, 허가는 녹색 글씨·거부는 붉은 글씨로 표시한다. 기존 사라짐과 중복 억제 동작은 유지한다.
- 카메라·AI 설정 상단에 표시 이름과 저장 버튼을 추가했다. 입력은 화면에 바로 반영되고 표시 이름 저장 또는 카메라 연결 시 역할별 AI 설정 JSON의 CameraDisplayName에 저장한다. 빈 이름은 기존 기본 이름으로 대체한다.
- 표시 이름은 화면용이며 CAM-01 통신 식별자·DB 카메라 키·녹화 경로를 바꾸지 않는다. 기존 설정 파일에 필드가 없으면 기본 이름을 사용한다.
- 사용자 제공 CCTV PNG를 클라이언트 창과 설정 창 아이콘 리소스로 추가했다. 동일 그림을 여러 해상도의 ICO로 변환해 실행 파일 ApplicationIcon에 지정했다. 원본 파일은 Assets/client-camera.png에 보존했다.
- 검증: 텍스트만 표시한 합성 영상과 표시 이름 설정 창의 WPF 렌더링 확인. 클라이언트와 등록 앱 빌드 경고·오류 0. 실행 파일 아이콘 포함 클라이언트 빌드도 경고·오류 0. 실제 카메라·서버 인증은 실행하지 않았다.

## 제목줄 아이콘 재교체

사용자가 새로 제공한 icons8 30×30 PNG를 서버와 클라이언트의 창·실행 파일 아이콘으로 사용한다. 16/20/24px은 원본에서 축소하고 30px은 원본을 유지하며 32px은 투명 여백만 추가한 다중 해상도 ICO를 만들었다. 작은 원본을 큰 이미지로 확대해 고해상도라고 취급하지 않는다. Window.Icon도 PNG 대신 다중 해상도 ICO 리소스를 참조한다. 클라이언트 설정 창에도 적용했다. 서버·클라이언트의 Assets/camera.png에 원본을 보존한다.

## 관제 서버 사이드바 접기

2026-10-26 사용자 요청으로 관제 서버 좌측 메뉴 상단에 사이드바 접기/펼치기 버튼을 추가했다. 펼친 폭은 220, 접힌 폭은 64이며 접힘 시 글자·분류 제목·하단 설명을 숨기고 아이콘과 메뉴 툴팁을 유지한다. 관제 영역은 남은 폭을 사용한다. 버튼은 사이드 패널 모양이며 재클릭하면 펼쳐진다. 통신·영상 처리와 기존 메뉴 기능은 변경하지 않는다.

서버 빌드 경고·오류 0, 장치·DB 연결 없는 실제 WPF 미리보기에서 접힘/펼침 배치를 확인했다. 실제 연결 중 마우스 전환은 별도 확인이 필요하다.
