# 설계와 리팩토링 결정

## 독립 도구와 통합본 유지

초기 독립 도구는 5방향·단일인 비교 실험이고 통합본은 WPF·서버·전체 직원 검색·녹화를 포함한다. 파일명 유사성만으로 통합하면 실험 재현과 별도 실행이 깨질 수 있어 이번에는 두 폴더를 유지했다. 공용 패키지 분리는 배포·의존성 전략을 결정한 뒤 검토한다.

## 반복 입력 정규화 제거

한 번의 참조 비교에서 입력은 같으므로 입력 정규화만 호출당 한 번 수행한다. 참조 정규화·딕셔너리 순서·코사인 거리와 기존 오류 차단은 유지한다. 샘플 전체 행렬화를 추가하면 계산 순서 변화가 생길 수 있어 이번에는 적용하지 않았다. 속도 향상률을 측정한 것은 아니다.

## 생성물 삭제와 실행 데이터 보존

재생성 가능한 obj·비실행 bin·Python 캐시만 삭제했다. 실행 중 앱의 bin, 모델·캐시, 이력·검사 자료는 사용 근거가 있어 보존했다. 원본 영상과 실제 DB는 정리 대상에 포함하지 않았다.

## 검증 환경과 실행 중 프로세스

대상 Python 3.11 환경으로 검증하고 다른 환경의 API 부재를 제품 코드 결함으로 오판하지 않았다. 실행 중 EXE 잠금은 앱 강제 종료 대신 별도 출력 경로 빌드로 확인했다.
