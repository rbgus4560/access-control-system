# 12.3 코드 정리본 적용 안내

## 변경 범위

- C# 64개, Python 26개 파일에 파일 역할 설명을 추가했다.
- 상태 변경·동기화·얼굴 식별·서버 권한 판정·녹화와 클립 처리의 주요 지점에 설명을 보강했다.
- C#과 Python의 압축된 문장·긴 인수 목록을 정리하고, XAML 12개와 프로젝트 파일 8개의 들여쓰기를 통일했다.
- `.editorconfig`와 `../guides/CODE_GUIDE_KO.md`를 추가했다.
- SQL 검사 스크립트가 C# 공백·줄바꿈 변경을 허용하도록 추출 정규식만 조정했다.

클래스 책임 재분리나 기능 변경은 이번 범위에 포함하지 않는다. DB 테이블·모델·비교 기준·등록 방식·통신 계약을 변경하지 않는 가독성 정리다. 버전 기준은 12.3이다.

## 적용 순서

1. 실행 중인 서버·클라이언트·등록 앱을 종료한다.
2. 기존 정상 `AccessControl_UI` 폴더를 보관하고, 이번 ZIP을 새 폴더에 압축 해제한다.
3. 같은 PC에서는 `Start_Server.cmd`로 서버를 실행하고 기존 DB 설정으로 연결한다.
4. `Start_Client.cmd`로 클라이언트를 실행해 서버 연결, 카메라 연결, 자동 보정·식별을 확인한다.
5. 서버의 직원·얼굴 등록 창과 녹화 재생·클립 기능을 짧게 확인한다.

이번 코드 정리 때문에 SQL을 다시 실행할 필요는 없다. 기존 `%LOCALAPPDATA%\AccessControlSystem` 데이터와 Python 가상환경·모델 캐시는 유지한다. 새 폴더에서 AI 경로 설정이 필요한 경우 이번 폴더의 `FaceAI`를 가리키는지 확인한다.

## 사용자 환경에서 확인된 기준 상태

- 기존 12.3에서 다른 직원 등록 및 전체 직원 자동 식별을 확인했다.
- 출입 권한 없는 직원과 미등록자의 거부를 확인했다.
- 과거 녹화 동기화 대기는 0건으로 확인했다.
- 파일과 작업 결과가 없는 과거 클립 요청 3건은 DB에서 FAILED로 정리했다.
- `access_control` 스키마의 사용자 지정 형식 DB 백업 파일을 만들었다. 파일 크기는 화면에서 약 559KB였으며, 복원 시험은 별도다.

위 항목은 코드 정리 전 사용자 환경의 확인 기록이다. 이번 ZIP의 Windows 카메라·화면 실기 확인과 실제 두 PC 네트워크 시험을 대신하지 않는다. 아래 방향 얼굴 등록이 약한 문제는 이번 정리로 수정하지 않았다.

검사는 Linux의 격리된 임시 데이터로 진행했다. 통합 검사 초기에 임시 경로 설정과 시간 제한에 걸린 실행은 완료로 계산하지 않았고, 존재하는 임시 경로를 지정하고 부하를 줄인 재실행에서 통과했다. 사용자 DB나 녹화 파일을 시험 대상으로 사용하지 않았다.
