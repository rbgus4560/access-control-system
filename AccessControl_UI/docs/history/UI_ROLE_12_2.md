# 12.2 · 큰 등록 카메라·목록형 메뉴·방향 안내 순서

## 적용

앱을 닫고 정상 폴더를 보존한 뒤 새 폴더에 ZIP을 푼다. Start_Server.cmd 실행. 추가 SQL·DB 초기화·새 모델 설치는 필요 없다. 기존 두 PC 전환용 15번 SQL을 아직 적용하지 않았다면 DB 기능 확인 전에 적용한다.

**등록 창 오른쪽 위 설정·진단에서 AI 폴더를 이번 ZIP 안 FaceAI로 지정한다.** 이전 버전 폴더를 가리키는 저장 설정이 남아 있으면 새 UI에서도 옛 Python 등록 로직을 실행할 수 있다. Python 실행 파일과 모델 캐시는 기존 정상 환경의 경로를 사용한다. 카메라 연결 중에는 설정이 잠기므로 연결 종료 후 변경한다.

## UI

- 서버·클라이언트: 테두리 버튼 대신 아이콘·텍스트의 목록형 메뉴. 선택 배경·왼쪽 파란 강조선, 키보드 포커스 표시. 설정은 사이드바 하단 고정. 메인으로 다시 돌아오면 관제/인증 항목 표시.
- 등록: 왼쪽 큰 영상(약 70%), 오른쪽 직원·연속 등록 패널. 원본 영상 비율을 유지하고 카메라를 늘린다. 작은 창에서는 오른쪽 내용만 스크롤하고 저장 영역은 아래에 고정한다.
- 영상 위에는 현재 행동 안내를 크게 표시한다. 실제 카메라 입력만 표시하며 시안의 인물 실루엣이나 예시 체크 상태를 영상처럼 넣지 않는다.
- 오른쪽에는 실제 감지 방향, 방향별 확정 샘플 개수, 완료·진행·대기를 표시한다. 정면은 1개, 좌우·상하는 각각 서로 다른 각도 2개다. 후보 1장을 받았다는 사실과 최종 대표 2개를 확정한 사실은 다르므로 각 방향은 선택이 확정되기 전 0/2로 보일 수 있다.
- 정면 보정·기준 초기화·Python 경로·반전 옵션·최근 분석 프레임·상세 진단은 별도 설정 창에 있다. 창을 닫았다 다시 열어도 같은 실제 컨트롤을 사용하며 등록 작업은 계속된다.
- 직원 조회 실패와 DB 저장 결과는 직원/저장 패널에서 확인한다. 서버 DB 연결이 필요하며 UI 변경이 DB 연결 실패를 자동 해결하는 것은 아니다.

## 등록 방향 안내 보강

기존 guided_enrollment는 현재 안내와 다른 방향의 움직임에서도 후보를 받아 다른 방향을 미리 완료할 수 있었다. 이 구조를 제거해 현재 안내 방향만 후보를 받게 했다. 이는 확인한 구조적 문제이며, 사용자가 본 좌측/상측 반복이 모두 이 원인이라고 실제 카메라에서 확정한 것은 아니다.

새 진행 순서:

1. 정면을 바라본 상태에서 등록 시작. 시작 프레임으로 정면 보정과 정면 샘플 선택.
2. 왼쪽 안내에 따라 천천히 회전. 두 대표 샘플 확정 후 정면 복귀 안내.
3. 정면 복귀가 확인되면 오른쪽 안내. 수집 완료 후 다시 정면.
4. 위 안내. 수집 완료 후 다시 정면.
5. 아래 안내. 두 대표 샘플이 확정되면 총 9개 완료. 직원 확인 후 DB 저장.

정면으로 복귀한 프레임은 단계 전환에 쓰고 정면 특징을 중복 저장하지 않는다. 움직임에서 자동 선별하는 방식은 유지한다. 정지 촬영·스페이스 키·같은 자세 두 번 촬영은 요구하지 않는다. 품질 기준·각도 차이·후보 상한·기존 완성 기준의 원자적 교체·다른 얼굴 거절·취소 시 이전 기준 보존을 유지한다.

좌우/상하가 물리적인 움직임과 반대로 감지되면 설정에서 반전 보정을 확인한다. 아래로 깊게 숙여 얼굴 검출 자체가 끊기는 현상은 별도다. 이번 변경은 dlib·MediaPipe 검출/자세 모델의 정확도를 개선한 것이 아니다.

## 내부 검사와 실제 확인

- Python 전체 40개 검사 통과. 안내와 다른 방향 거절, 정면 복귀를 포함한 순서, 완료·내보내기·취소를 실제 worker 경로와 가짜 모델로 검사. OpenCV MP4 관련 검사도 포함. 실제 사람·카메라 모델 추론은 아님.
- .NET 10 세 WPF 앱 빌드 통과. 실제 Windows 레이아웃·설정 창 재열기는 사용자 PC에서 확인.
- Network/FaceService/Database 및 녹화·파일 전송 코드는 12.1을 유지. 얼굴 특징 형식·모델·비교 임계값·DB 스키마는 바꾸지 않았다.
- Windows에서는 새 FaceAI 경로 확인 후 정면·왼쪽·정면·오른쪽·정면·위·정면·아래 순서가 실제로 안내되는지, 오른쪽 패널의 실제 감지 방향이 움직임과 맞는지 확인한다. 새로 선택한 9개를 DB에 저장하고 클라이언트에서 불러오기/본인·타인 확인을 진행한다.
- 두 PC LAN 실측은 내일 ../guides/DEPLOY_TWO_PC.md 순서로 진행한다. UI 시안은 실제 실행 화면의 픽셀 단위 복제나 실제 검증 결과가 아니다.
