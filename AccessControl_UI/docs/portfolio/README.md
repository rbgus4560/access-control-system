# 출입관제 발표 원고

핵심 기술은 TCP/IP 기반 클라이언트 서버 연결과 AI 얼굴 식별 두 가지로 설명한다. DB는 저장과 권한 확인을 지원하는 요소다. 기술을 사용해 무엇을 구현했는지와 실제 소스 근거를 함께 정리했다.

- [핵심 기술 슬라이드 문구와 발표](01_핵심기술_TCPIP_AI_슬라이드와발표.md)
- [사용 기술 해설](02_사용기술_초보자용_해설.md)
- [문제 해결 두 사례와 공통 배운 점](03_문제해결과배운점_TLS_아래방향등록.md)

문제 해결과 배운 점은 한 슬라이드에 요약하고, 상세 설명은 발표 노트로 사용한다. 기존 모델을 직접 학습했다고 표현하지 않는다. 빌드·합성 검사와 실제 카메라·LAN·운영 DB 검증을 구분한다.
