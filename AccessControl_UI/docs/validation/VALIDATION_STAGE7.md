# 7단계 TCP 연결 검증 기록 — 2026-10-18

## 개발 환경에서 통과한 검사

- .NET SDK 8.0.426: FaceRecognition, FaceEnrollment, AccessControlServer WPF 빌드
- 실제 IPv4 127.0.0.1 TCP 소켓으로 상태 송수신 및 같은 세션·순번의 ACK 수신
- 서버 중지 및 동일 포트 재시작 후 자동 재접속
- 잘못된 크기 메시지를 보낸 연결 종료 후 새 클라이언트 정상 수신
- 헤더 일부만 전송하는 연결의 5초 제한 및 후속 연결 복구
- 한글 JSON 보존, 16KiB 크기 상한, 버전·세션·순번·상태 정합성 검증
- 미반영 명령, 오래된 분석, 다중 얼굴, 얼굴 이탈, 비교 꺼짐에서 거리 전송 중지
- 새 AI 이벤트가 없어도 경과 시간에 따라 스냅샷을 만료 처리
- 본인 후보와 불일치가 모두 올바른 거리 기준으로 변환됨

## 아직 사용자 PC에서 확인할 검사

1. 새 7.0 앱 두 개 실행, 서버 시작 및 인증 앱 서버 연결
2. 카메라 없이 ACK 번호 증가 및 서버 장치 수신 표시
3. 서버 중지·재시작 시 미연결·재접속 표시
4. 실제 얼굴 비교에서 본인 후보·타인 불일치 수신
5. 얼굴 이탈·다중 얼굴·AI 연결 종료 시 거리 숨김
6. 앱 종료 후 TCP 포트와 카메라 해제

현재 수신 목록은 메모리의 관찰 이력이다. 권한이 없는 직원의 거절과 출입 이벤트 DB 저장은 9단계에서 검증한다. 이 문서의 내부 통과 결과를 사용자 PC의 최종 검증 완료로 해석하지 않는다.

## 통신 형식

4바이트 big-endian 길이, 최대 16384바이트 UTF-8 JSON. Version=1, Type=snapshot 또는 ack. Session은 연결별 UUID, Sequence는 1부터 증가. 장치 코드 RECOGNITION-01 및 CAM-01. 수신 확인은 같은 세션·순번을 반환한다. 약 1초 주기로 마지막 분석 관찰을 송신하고 성공 응답이 없으면 5초 내 해당 연결을 종료하며 2초 후 재접속을 시도한다.

단일 PC 시연 범위여서 서버는 127.0.0.1에만 바인딩한다. 소켓 쓰기·읽기는 UI 스레드와 분리했다. UI 수신 목록은 상태 변경만 최대 500건 보관한다. 원본 영상, 얼굴 특징, DB 비밀번호는 이 메시지에 포함되지 않는다.

서버는 마지막 분석 나이가 2.5초를 초과하면 이전 일치 표시를 숨긴다. 상태 갱신 주기 500ms로 인해 화면 만료 표시에는 최대 약 500ms의 차이가 있을 수 있다. 수신 상태는 출입 허가 판정이 아니다.
