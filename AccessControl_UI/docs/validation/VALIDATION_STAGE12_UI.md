# 11.0 · WPF UI 화면 정리

## 적용

1. 정상 동작한 10.8 폴더를 보관한다. 카메라 연결을 종료하고 서버·인증·등록 앱을 모두 닫는다.
2. ZIP의 AccessControl_UI 내용을 기존 폴더에 덮어쓴다. 사용자 DB·모델 캐시·로컬 녹화 폴더는 패키지에 포함하지 않는다.
3. Start_Net10.cmd 실행. 최초에는 새 WPF-UI NuGet 패키지를 다운로드하므로 인터넷 연결이 필요하며 기존보다 시간이 걸릴 수 있다. 빌드 실패 시 오류 창을 닫지 말고 내용을 확인한다.
4. 창 제목 11.0 확인. 기존 방식으로 서버 DB 연결·관리자 선택·TCP 시작, 인증 앱 서버 연결·직원 조회·DB 얼굴 기준 불러오기.
5. 추가 SQL 실행이나 얼굴 재등록은 필요 없다. 이미 14번 SQL과 자동 선택 샘플 저장을 적용한 상태를 기준으로 한다. 새로운 PC에서는 기존 DB 설치 절차를 먼저 따른다.

## 화면 변경

- WPF-UI 4.3.0을 세 WPF 앱에 NuGet 의존성으로 추가했다. Light ThemesDictionary와 ControlsDictionary, 실제 WPF UI Button·SymbolIcon을 사용한다. Gallery 프로그램을 별도로 설치할 필요는 없다.
- 밝은 배경·흰 카드·파란색 주요 버튼·통일된 간격과 글꼴을 적용한다. 팝업의 기존 기본 버튼·표도 공통 스타일로 정리한다.
- 인증: 왼쪽 직원 기준·서버 연결·녹화 상태, 가운데 큰 실시간 카메라 한 개, 상단 출입 판정, 하단 24시간 타임라인 유지. 클립 추출과 LIVE 복귀는 타임라인 위에 배치한다.
- 최근 분석 프레임·처리 시간·원문 AI 메시지는 분석 상세를 펼쳐 확인한다. 메인 영상에 느린 분석 화면을 나란히 상시 표시하지 않는다. 분석 자체·비교·녹화 속도 로직은 그대로다.
- 등록: 직원 선택 영역·큰 카메라·수집 안내·진행률·하단 저장 영역을 구분한다. 움직임 수집은 10.8과 동일하다. 시작할 때 정면을 바라보고, 안내에 따라 천천히 움직인다. 완료 후 선택 직원 확인과 DB 저장.
- 서버: 연결 및 관리자 설정을 접을 수 있다. DB 연결·관리자 선택·TCP 시작 후 설정을 접으면 영상 공간이 커진다. 직원 관리·녹화 구간은 상단, 출입 기록·선택 영상·상세는 하단이다.
- 허가·거부·연결·녹화 상태는 실제 기존 로직에서 갱신한다. 장식용 정상 상태나 임의 성능 수치를 추가하지 않는다.

## 내부 검증

- .NET 10에서 WPF-UI 4.3.0 패키지 복원 및 세 앱 빌드 성공. 세 앱의 공통 테마 BAML이 실제 리소스에 포함됐음을 확인했다.
- 이전 10.8과 비교해 세 메인 화면의 모든 기존 이름 있는 컨트롤과 Click/Closing/SelectionChanged/MouseDoubleClick 이벤트 연결을 유지했다.
- FaceAI·FaceService·Network·Database 53개 파일은 10.8과 바이트 단위로 동일하다. 등록 모델·대표 선택·DB 저장 계약·출입 정책·TCP·SQL을 UI 변경에 섞지 않았다.
- 10.8 내부 검사(Python 39개·C# 계약/통신/영상/보관·임시 PostgreSQL 마이그레이션) 결과는 이전 문서에 기록했다. 이번에는 변경한 WPF 의존성과 화면 빌드·리소스·이벤트 연결을 확인했다.
- Linux에서 Windows WPF 창을 실제 실행하거나 배치를 렌더링한 것은 아니다. 실제 표시·DPI 배율·키보드 동작·팝업·미디어 재생은 아래 Windows 절차로 확인한다.

## Windows 확인 순서

1. 인증·서버·등록 세 창이 열리고 글자·버튼·카메라·저장 영역이 잘리지 않는지 확인. 필요 시 창을 최대화한다.
2. 서버 DB 연결·관리자 선택·TCP 시작. 설정 영역 접기/다시 열기.
3. 인증 앱 서버 연결·DB 기준 9개 불러오기. 카메라 연결 후 AI 준비·기준 적용·정면 보정·비교 시작, 본인 후보와 실제 서버 GRANTED/DB 기록 확인.
4. 얼굴 이탈 시 대기 복귀, 서버 영상 표시, 녹화 상태 확인. 분석 상세 펼치기/닫기와 카메라 연결 종료/재연결 확인.
5. 기존 녹화 타임라인 조회·재생·LIVE 복귀와 클립 추출창 확인. 원본 보관 72시간 상태도 유지되는지 확인.
6. 인증 카메라 종료 후 등록 창 열기·직원 조회·자동 등록 안내·DB 저장 버튼 확인. UI 확인만을 위해 이미 저장한 얼굴을 반드시 다시 등록할 필요는 없다.
