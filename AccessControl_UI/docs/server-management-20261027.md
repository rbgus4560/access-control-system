# 관제 이름 동기화와 관리 메뉴

2026-10-27 사용자 요청으로 이름·상태 표시·메뉴와 직원 삭제를 수정했다.

## 이름과 상태

이전 CameraDisplayName은 클라이언트에만 저장되어 서버에 반영되지 않았다. VideoPacket에 선택적 CameraDisplayName을 추가하고 클라이언트가 매 프레임 메타데이터로 보내도록 했다. 기존 메시지는 빈 이름을 기본값으로 읽는다. 최대 60자·제어문자 제한을 적용한다. 서버는 해당 이름을 타일 및 열린 확대 창에 반영한다. DB 카메라 코드와 녹화 경로는 변경하지 않는다. 송신 스레드가 WPF TextBox를 읽지 않도록 UI에서 문자열 스냅샷을 갱신해 전달한다.

각 카메라 하단 상태 줄은 기존 배경보다 밝은 #28384C로 구분한다. 상단 DB/TCP/IP/영상 아이콘에 마우스를 올리면 카메라 내부 설명이 표시된다. 메뉴 항목 툴팁은 제거했다.

## 메뉴 정리

직원 관리를 누르면 직원·출입 권한과 얼굴 등록이 아래로 펼쳐진다. 기록 및 영상도 같은 방식으로 펼쳐지며 높이를 180ms 동안 늘린다. 접힌 사이드바에서는 아이콘 접근을 유지한다.

기록 및 영상은 출입 기록과 영상 조회·클립의 두 기능으로 나눈다. 녹화 구간 목록은 주 메뉴에서 제거하고 영상 창의 녹화 상태 점검 버튼으로 이동했다. 원본 구간 진단 기능 자체는 보존했다.

## 직원 삭제

사용자는 기존 출입 기록을 보존하는 삭제 처리를 선택했다. 직원 관리에서 대상을 선택하면 삭제 버튼을 사용할 수 있고 확인 후 처리한다. deleted_at 기록·직원 비활성·출입 권한 해제와 활성 얼굴 등록 중지를 하나의 트랜잭션으로 실행한다. 갱신 시각을 비교해 동시 수정 충돌을 막는다. 기본 직원·등록 목록과 수정 대상에서 삭제된 직원을 제외한다. 과거 직원 행·출입 이벤트·등록 이력은 보존하며 사원번호를 다른 사람에게 자동 재사용하지 않는다.

**DB 준비:** Database/16_employee_archive.sql을 대상 DB에 한 번 적용해야 한다. 일반 삭제 처리에서 자동 DDL은 실행하지 않는다. 컬럼이 없으면 삭제를 중단하고 SQL 경로를 안내한다. 이번 작업에서는 실제 DB 마이그레이션·직원 삭제를 실행하지 않았다. 운영 DB에서의 트랜잭션·롤백·권한 및 동시 작업 검증은 남아 있다.

## 검증

서버·클라이언트 빌드 경고·오류 0. 실제 WPF 미리보기로 펼친 그룹 메뉴, 내부 상태 설명, 밝은 상태 줄, 직원 삭제 버튼 배치를 확인했다. 합성/빈 상태 미리보기이며 실기 검증은 아니다.

전체 NetworkChecks는 Actual TCP exchange failed로 실패했다. 이번 변경의 이름 전송·이전 메시지 호환·비정상 이름 거부·메시지 제한은 --video-metadata-only 경로로 별도 검사한다. 전체 TCP 성공으로 해석하면 안 된다.

적용 시 서버와 클라이언트를 모두 재시작해야 이름 전송 필드가 반영된다. 구버전 클라이언트는 이름을 보내지 않는다.

## 그룹 아이콘과 타일 상태 설명 후속 수정

직원 관리 헤더는 사람 모음, 기록 및 영상 헤더는 폴더 아이콘으로 구분했다. 하위 메뉴는 사람·사람 추가·문서·영상 아이콘을 사용한다. 접힌 사이드바에서 Expander의 기본 테두리·화살표가 좁은 폭을 차지하던 템플릿을 교체했다. 헤더 아이콘만 남고 클릭 시 하위 아이콘이 높이 애니메이션으로 펼쳐진다. 사이드바 전환 시 그룹은 닫힌 상태로 시작한다.

카메라 이름은 영상 오버레이와 별개로 하단 상태 줄에도 반영하도록 고쳤다. 이전 하단은 cameraCode 상수만 표시해 이름이 바뀌지 않았다. 타일 아래 카메라·서버 아이콘과 표시등을 투명 Border로 함께 묶어 전체 영역의 MouseEnter/Leave로 타일 내부 안내를 표시한다. 기존에는 표시등에만 ToolTip이 있어 아이콘 위에서는 나오지 않았다.

서버 빌드 경고·오류 0. 접힌 그룹 아이콘과 펼친 그룹/하위 아이콘 배치를 WPF 미리보기로 확인했다. 실제 클릭 애니메이션·마우스 안내 및 실기 이름 전달은 재확인이 필요하다.
