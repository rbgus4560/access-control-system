# 출입 기록 필터와 시간 표시

- 선택 기록 영상 버튼을 다른 조회 버튼과 동일한 Secondary 색으로 변경했다.
- 시작일과 종료일은 해당 날짜를 포함해 조회된 기록을 필터링한다. 미지정 날짜는 제한하지 않는다.
- 분류는 카메라, 사원번호, 이름, 결과, 사유의 드롭다운이다. 각 분류 옆의 값 드롭다운에서 전체 또는 조회된 값을 선택한다.
- + 버튼은 중복 없는 분류를 추가하며 최대 5개에서 비활성화된다. 여러 조건은 AND로 적용한다.
- 필터 범위는 DB에서 조회한 최근 500건이다. 메인 관제의 최근 기록에는 필터를 적용하지 않는다.
- 재생 오버레이, 재생 시각 입력 초기값, 구간 선택 목록, 녹화 DB 목록은 초까지만 표시한다. 원본 데이터와 통신 시간 정밀도는 변경하지 않는다.
- 서버 메인 창 제목은 Access Control · 서버로 단순화하고 사이드바 하단 SERVER / CAM-01 및 설명을 제거했다.

검증: 서버 빌드, --history-filters-preview의 합성 기록으로 분류 5개의 고유성/추가 한도, 결과 필터, 날짜 필터 검증 및 화면 캡처. 실제 DB 조회와 녹화 재생은 이번 검증에 포함하지 않았다.

후속 UI 정리: 제목 아래 설명, 최근 출입 기록 소제목, 조회 건수 문구를 숨겼다. 분류/값 드롭다운 폭을 62/76로 줄이고 5개를 한 줄에 배치했다. 작은 창에서는 가로 스크롤로 줄바꿈을 방지한다. 빌드 경고/오류 0, 분류 5개 미리보기로 확인했다.

재생 도구 정리: 날짜 선택은 일자까지 표시하는 Short 형식과 폭 155를 사용한다. 구간 선택은 폭 190, 시각 입력은 폭 80으로 축소하고 텍스트를 중앙 정렬한다. 타임라인 범례와 맨 아래 중복 안내를 제거했다. 재생 중 영상 영역의 상태 표시는 유지한다. 서버 빌드로 검증했으며 실제 녹화 재생은 미검증이다.


## 검색 방식으로 변경

분류와 + 버튼을 제거하고 기간·검색·조회·영상·상세 버튼을 한 줄로 배치했다. 검색은 조회된 최근 500건의 카메라/사원번호/이름/결과/사유에서 대소문자 구분 없이 부분 일치하며 기간과 함께 적용한다. 날짜는 en-CA Short 형식과 폭 145로 일자까지 표시한다. 빌드 경고/오류 0. 합성 기록의 검색 포함/제외, 기간 필터 검사와 날짜를 채운 캡처로 확인했다. 앞의 분류 방식은 변경 전 이력이다.


## 표 정렬 통일

직원 관리의 접속 정보/안내 및 하단 조회 상태 문구를 숨기고 검색·신규 버튼에 8px 간격을 적용했다. 서버·클라이언트·얼굴 등록 공통 테마의 표 열을 동일 비율로 배분하고 헤더와 셀 내용을 중앙 정렬했다. 직원 관리와 최근 기록의 고정 열 너비도 균등 배분으로 변경했다. 세 프로젝트 빌드 경고/오류 0 및 합성 직원 화면 캡처로 검증했다. 실제 DB 조작은 수행하지 않았다.


## 드롭다운 외형 통일

세 앱 공통 테마에서 ComboBox를 높이 34, 흰 배경, 연한 버튼 테두리 및 둥근 모서리로 통일했다. 기본 OS 회색 그라데이션을 제거하고 펼친 목록은 흰색, 강조/선택은 연한 파랑으로 표시한다. 편집 가능한 서버 주소 입력과 키보드/팝업 기능을 위한 기본 파트를 유지했다. 세 프로젝트 빌드 경고/오류 0.


드롭다운 외형 통일은 사용자 요청으로 취소했다. 세 앱의 ComboBox 테마와 재생 목록 아이템 스타일을 변경 직전으로 복원했다. 표 정렬·검색·날짜 및 다른 화면 수정은 유지한다.


## 조회 버튼 적용 및 재생 도구 정리

검색·날짜 입력 이벤트의 즉시 Refresh를 제거했다. 기록 조회 버튼에서 조건을 별도 값으로 확정해 적용하며 입력 도중에는 기존 결과를 유지한다. 기록 추가마다 전체 필터를 재실행하던 이벤트도 제거했다. 합성 기록 검증에서 입력 후 결과 유지, 적용 후 검색 포함/제외 및 기간 조건을 확인했다. 재생 도구는 날짜/구간/시각 묶음과 재생/보기 줄로 구분하고 관련 입력·버튼 높이를 34로 맞췄다. 전역 드롭다운 색상은 변경하지 않았다. 얼굴 등록의 제목 아래 안내 두 줄, 미러링 설명 및 연속 문구를 제거했다. 서버·얼굴 등록 빌드 경고/오류 0, 재생 도구 미리보기 확인. 실제 DB/녹화 재생은 미검증이다.


재생 도구 후속 정리: 클립 요청/녹화 상태 점검을 타임라인 위 오른쪽으로 이동했다. 날짜·구간·시각은 동일한 흰 배경 묶음 안에 라벨, 입력, 실행 버튼을 배치하고 글자 13과 높이를 맞췄다. 구간 드롭다운은 이 패널에만 평면 템플릿을 적용해 회색 배경을 제거했다. 전역 드롭다운 스타일은 유지한다. 서버 빌드 경고/오류 0, 재생 도구 미리보기 캡처로 확인했다.


등록 UI 후속 변경: 큰 직원 얼굴 등록 제목을 제거하고 설정·진단을 얼굴 등록 섹션 오른쪽으로 이동했다. 연결/종료, 등록 시작/취소는 같은 자리에 긴 파란 버튼으로 배치하며 기존 연결/등록 상태 응답에 따라 하나만 표시한다. 재생 구간 팝업은 세로 스크롤바 공간을 항상 확보하고 항목과 여백을 분리했다. 세 프로젝트 빌드 경고/오류 0 및 등록 화면 미리보기 확인. 실제 카메라 연결/등록은 미검증이다.


## 한국어 달력

영어 달력 원인인 출입 기록 DatePicker의 en-CA 지정값을 ko-KR로 바꾸고 세 앱의 날짜 선택에 한국어 달력 스타일을 적용했다. 월/요일 한글, 넉넉한 날짜 셀, 선택일 파란 원과 오늘 테두리, 다른 달의 연한 글자로 구분한다. 날짜 입력은 Short 형식과 최소 폭 155를 사용한다. 세 프로젝트 빌드 경고/오류 0, --calendar-preview 캡처로 한국어와 선택일 표시를 확인했다.


드롭다운 겹침 재수정: 기본 ScrollViewer 템플릿이 항목 위에 스크롤바를 그릴 가능성을 제거하기 위해 항목과 세로 스크롤바를 별도 열로 배치하는 전용 템플릿을 적용했다. 세 앱의 ComboBox와 재생 구간은 동일한 벡터 꺾쇠 화살표를 사용하며 텍스트와 화살표 공간도 분리한다. 편집 가능한 콤보의 PART_EditableTextBox를 유지했다. 세 프로젝트 빌드 경고/오류 0, 재생 도구 미리보기 확인. 실제 긴 목록에서 마우스 선택/스크롤은 미검증이다.


날짜 입력 외형 통일: 모든 DatePicker에 흰 입력칸, 연한 둥근 테두리, 오른쪽 작은 벡터 달력 아이콘을 적용했다. 팝업은 공통 한국어 달력을 사용하고 선택일은 채움 대신 파란 원 테두리로 표시한다. 세 프로젝트 빌드 경고/오류 0. 날짜 입력과 달력 미리보기 캡처를 확인했다.
