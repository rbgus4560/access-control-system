# 서버 카메라 목록과 화면 배치

- 서버관제를 펼치면 수신한 카메라 목록이 표시된다. 연결이 끊긴 카메라는 미연결로 표시한다.
- 카메라를 선택한 다음 9분할 중 원하는 화면을 클릭하면 해당 칸으로 이동한다. 동일 영상을 여러 칸에 복제하지 않는다.
- 화면 배치는 사용자 LocalAppData/AccessControlSystem/server-camera-layout.json에 저장하며 다음 실행에 복구한다.
- 후속 요청에 따라 그룹 기능과 그룹 추가 버튼을 제거했다. 과거 설정 파일의 그룹 필드는 무시하고 카메라 목록을 직접 표시한다.
- 카메라명은 클라이언트가 영상 패킷에 보낸 표시명을 사용한다.
- 하단 아이콘 설명은 해당 아이콘 바로 위, 타일 안쪽에 표시한다. 서버 관점의 용어는 영상 수신/미수신, 클라이언트 연결/미연결이다.

현재 통신 구현이 지원하는 실제 카메라는 CAM-01 하나다. 이 변경은 목록과 배치 기능이며 다중 클라이언트 통신 지원을 추가하지 않는다.

## 사이드바 후속 수정

접힌 메뉴에서 상위 아이콘이 왼쪽으로 치우치고 카메라 버튼에 기본 테두리가 나타났다. 상위 메뉴 헤더를 가운데 정렬하고 카메라 버튼에 테두리 없는 전용 템플릿을 적용했다. 상위 메뉴에는 연한 배경을 적용하고 하위 목록까지 하나의 외곽 테두리로 묶어 계층을 구분한다. 서버 빌드 경고/오류 0, 접힌 상태와 펼친 상태의 합성 영상 미리보기 캡처로 확인했다.

추가 정정: 연한 헤더 배경과 외곽 테두리는 메뉴가 펼쳐졌을 때만 표시한다. 메뉴가 닫혀 있으면 배경과 선은 투명하게 유지한다. IsExpanded 트리거로 표시를 전환하며 닫힌 메뉴와 아이콘 모드의 열린 메뉴 미리보기를 확인했다. 빌드 경고/오류 0.

미연결 표시 정정: 하단 상태줄은 수신 가능한 영상이 없으면 카메라명 대신 `빈 화면`으로 표시한다. 영상이 수신되면 클라이언트의 카메라명으로 복귀한다. 저장된 화면 배치는 유지한다. 서버 빌드 경고/오류 0.

검증: 서버 빌드 성공(경고/오류 0). --ui-preview --camera-placement-preview로 CAM-01을 5번 칸에 배치하고 중복 할당이 없는지 검증했으며 화면 캡처로 확인했다. 미리보기는 개인 설정을 읽거나 저장하지 않는다. 실제 카메라/네트워크 연동과 사용자 설정 저장 후 재시작은 이번 검증에 포함하지 않았다.
