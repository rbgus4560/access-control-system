# 검증 기록

## 완료

- Python 소스 전체 구문 검사 통과.
- 수치·등록 상태 단위 검사 4개 통과: 잘못된 특징값 거부, 코사인 거리, 방향 구간·부호, 5방향 완성 전 활성화 방지와 재등록 취소·교체.
- 묶음 제공 MediaPipe·dlib 모델 SHA-256 확인 통과.
- 별도 Linux Python 3.12 환경에서 requirements.txt 패키지 설치 및 pip check 통과. 사용자 실행 대상은 Windows Python 3.11이므로 동일 환경 검증은 아님.
- MediaPipe 0.10.21 실제 CPU 추론: 빈 영상 0개, NASA 우주비행사 테스트 사진 얼굴 1개·478개 지점, 두 얼굴을 가까이 배치한 테스트 이미지 2개 검출.
- 얼굴 회전 행렬을 자기 자신을 기준으로 보정한 상대각 0도 확인.
- DeepFace 0.0.93에서 ArcFace 모델 실제 가중치 다운로드·로딩 통과 (입력 112×112, 출력 512).

## 실제 통합 경로 점검 완료 (Linux CPU / Python 3.12)

- dlib 19.24.6 + DeepFace 0.0.93 + MediaPipe 0.10.21로 전체 FaceEngine 실행.
- 빈 영상과 두 얼굴 테스트 이미지 거부.
- NASA 우주비행사 테스트 사진에서 검출·눈 기반 정렬·메시·ArcFace 특징 추출 통과.
- 특징 길이 512, 동일 입력을 독립적으로 처리한 코사인 거리 약 0.000000.
- 다른 인물 테스트 사진과의 코사인 거리 약 0.889027 (검증용 기준 0.45에서 불일치).
- 같은 사진 특징으로 채운 메모리 기준 5개를 이용한 비교 호출 정상 동작. 실제 5방향 촬영 데이터 검증을 뜻하지 않음.
- 위 사진 2장으로 측정한 값은 일반 인식 정확도·오인식률·임계값 적정성 근거가 아님.
- 실제 카메라 입력과 Windows UI는 실행하지 않음.

## 실제 Windows PC에서 확인 필요

- Conda 환경 생성과 dlib 바이너리 설치.
- OpenCV 카메라·화면·키 입력, 장치 번호·백엔드.
- 실제 정면·상하·좌우 방향의 부호와 안정성.
- 본인 5방향 등록 완주, 본인·타인 비교 점수·처리 속도.
- 조명·거리·안경·측면 조건의 오인식·미인식.

테스트 사진은 배포 ZIP에 포함하지 않음. 사진 한두 장이나 같은 입력의 특징 재현성 확인은 인식 정확도·오인식률 평가를 뜻하지 않음.
카메라 실사용·C# 연동·DB 저장·출입 권한 판정은 아직 검증하지 않음.

## v2 변경 검증

- 기존 4개 검사와 비동기 처리 검사 3개, 총 7개 통과.
- 최신 프레임 큐의 누적 방지, 오래된 결과·미반영 명령의 결과 숨김 확인.
- Windows와 같은 spawn 방식의 별도 AI 프로세스에서 명령 시점 이후 프레임으로 보정하는 경로 확인.
- 테스트용 엔진에서 여러 얼굴 비교 중단·안내, 모델 예외 후 결과 무효화·초기화 명령 처리 확인.
- 실제 dlib/MediaPipe/ArcFace 전체 경로 재검증: 512차원 추출, 같은 입력 거리 약 0, 다른 테스트 인물 거리 약 0.889027 재현.
- 카메라·Windows GUI에서의 실제 개선 정도와 처리 단계별 시간은 사용자 PC에서 확인 필요.

- 실제 모델을 사용하는 spawn 프로세스 검사 통과: 새 프레임의 정면 보정, 두 얼굴 안내·비교 중단, 빈 영상 거부, 단계별 시간 측정.
- 테스트 입력(818×818 우주비행사 사진)에서는 mesh 약 17ms, dlib+정렬 약 1330ms. 두 얼굴 테스트에서는 mesh 약 21ms, dlib·ArcFace 미실행. 서로 다른 입력·Linux 환경의 단일 검사이며 사용자 PC의 수치나 벤치마크가 아님.

- 실카메라 대신 테스트 영상을 공급하고 GUI 출력 함수를 대체한 Linux 검사에서, 실제 AI 프로세스와 함께 화면 구성 루프 210회 실행·종료 통과. 약 27.5fps로 갱신됨. 실제 Windows 창·USB 카메라 성능 측정은 아님.

## v3 변경 검증

- 기존 상태·비동기 제어 검사와 좌표 복원·경계 검사 총 9개 통과.
- 실제 모델 전체 경로 통과: 원본 영상에서 5점 랜드마크·눈 정렬, 512차원 특징, 같은 입력 거리 0, 다른 테스트 인물 거리 약 0.914155.
- spawn AI 프로세스의 정면 보정·여러 얼굴 안내·빈 영상 거부와 새 시간 필드 확인.
- 같은 우주비행사 테스트 사진을 기존/fast 방식으로 처리했을 때 특징 간 거리 약 0.103909. 검출 박스와 정렬 결과가 완전히 같지는 않음.
- 640×640으로 만든 별도 테스트 사진은 기존 방식에서 복수 dlib 영역이 검출되어 거부됨. 여러 얼굴은 검출 결과에 따라 판정하며, 한 장의 사진만으로 일반 검출 성능을 판단할 수 없음.
- v3는 검출 입력 크기·확대 횟수를 변경했으므로 실제 5방향 검출, 본인/타인 비교, 작은 얼굴·옆얼굴 조건은 Windows 카메라에서 재확인 필요.

- 별도 AI 작업을 동시에 실행하지 않고 비교한 참고 측정: 같은 818×818 테스트 이미지, 각 모드 준비 실행 1회 후 3회의 observe 중앙값. 기존 약 1204.83ms, fast 약 209.35ms. 특징 추출 시간은 제외한 검출·메시·품질 검사 시간이며 Windows 카메라 수치가 아님. 표본 1장의 기능·속도 확인이고 통제된 성능 평가가 아님.
